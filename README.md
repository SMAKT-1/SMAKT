# SMAKT — Simulation-Based Evaluation Pipeline

Code and result files for: *"SMAKT: A Five-Layer Architecture for Integrating
Affect-Aware Computing into Industrial Decision Support — Design and
Simulation-Based Evaluation."*

## Contents

| File | Role |
|---|---|
| `run_experiments.py` | End-to-end pipeline producing every number in the paper (E1–E10 + sensitivity grid) |
| `agent_model.py` | Worker agent model (homeostatic affect dynamics + calibrated sensor model) |
| `config.py` | Central configuration (agent, environment, economic parameters) |
| `layer_*.py` | Reference implementations of the SMAKT layers 1/2/4/5 contracts |
| `results/` | Machine-readable outputs (CSV/JSON) + figures |

## Requirements

- Python 3.11
- numpy 2.3.1, pandas 2.2.3, scikit-learn 1.5.2, matplotlib

Install:

```bash
pip install -r requirements.txt
```

## Reproducing every reported number

```bash
python run_experiments.py
```

All experiments run from this single script with fixed seeds (base seed 42;
scenario-specific seed offsets documented in the code). Every table value in
the manuscript is generated by this script and written to `./results/`.

Experiment ↔ manuscript mapping: E1 dataset protocol (§5.2), E2 fusion +
majority baseline + worker-grouped CV (§6.1), E3 latency with held-out test
accuracy (§6.2), E4 robustness (§6.3), E5 culture (§6.4), E6 drift incl.
label-free PSI detector (§6.5), E7 degradation (§6.6), E8 scalability (§6.7),
E9 thresholds (§6.8), E10 five-arm comparative closed loop (§6.9), E10s
sensitivity grid (§6.9, Table 11). Total runtime on a standard desktop:
several hours (E10 with 30 replications × 4 arms plus the sensitivity grid
dominates; reduce `N_REP` in `run_comparative_experiment` for a smoke pass).

## Key design notes

- **Data-generating process:** bounded homeostatic affect dynamics (30%
  hourly relaxation toward heterogeneous individual baselines, ±0.12), a
  five-day work week with partial weekend recovery, and a two-workday
  burn-in discarded before recording — so training and deployment
  populations are drawn from the same stationary distribution.
- **Calibrated partial observability:** each affective state is expressed
  weakly and differently in each modality group (stress: HRV-dominant;
  engagement/frustration: speech-dominant; MES weak for stress); cultural
  display rules attenuate expressed signals only, never latent states or
  physiological HRV.
- **Labels** are binarized at reference-population quantiles (70th/30th
  percentile), computed after burn-in; class prevalence 25–33%.
- **Splits are by worker** (70/30); recognition experiments additionally
  report 5-fold × 5-repeat worker-grouped cross-validation.
- **E10** runs four intervention policies with shared seed sets: business-
  as-usual; model-targeted (fused stress model, weekly closing-hour
  snapshot, ≥0.6 threshold — the E9 precision-oriented operating point);
  volume-matched random (the same number of workers per week, chosen
  uniformly); treat-everyone. an oracle arm that replays the model arm's per-week flag volume selecting the true highest-stress workers (perfect knowledge, matched volume). All arms share 55% human acceptance, identical dynamics, and the activated disturbance-event machinery.
- **ROI** includes intervention delivery cost (30 USD per executed career
  conversation) and does not monetize the within-noise defect difference.
- The **E6 drift alarm** is a label-free population-stability-index (PSI)
  detector on input features (threshold 0.25), evaluated over 20 shifted
  and 20 unshifted validation pairs alongside the labelled accuracy-drop
  rule.
