## Requirements

- Python 3.11
- `numpy==2.3.1`, `pandas==2.2.3`, `scikit-learn==1.5.2`, `matplotlib==3.10.1`

Install:

```bash
pip install -r requirements.txt
```

The committed `results/` files were generated with exactly the versions pinned in `requirements.txt`; re-running the pipeline under these pins reproduces E1–E2 bit-identically (dataset statistics and every recognition/CV row).

## Reproducing every reported number

```bash
python run_experiments.py
```

All experiments run from this single script with fixed seeds (base seed 42; scenario-specific seed offsets are documented in the code). Every number in Section 6 of the manuscript is generated by this script and written to `./results/`.

Total runtime on a standard desktop is several hours; the closed-loop experiment E10 (30 replications × 5 arms) plus the sensitivity grid dominates. For a quick smoke pass, reduce `N_REP` (default 30) in `run_comparative_experiment()`.

## Key design notes

- **Data-generating process:** bounded homeostatic affect dynamics (30% hourly relaxation toward heterogeneous individual baselines drawn ±0.15 around the population default), a five-day work week with partial weekend recovery, and a two-workday burn-in discarded before recording — so training and deployment populations are drawn from the same stationary distribution.
- **Disturbance events** (machine breakdowns, quality alerts, management announcements; daily probability 0.15, cohorts of 5–20 workers) are active **only** in the closed-loop experiment E10; the recognition experiments (E1–E9) use an event-free data-generating process.
- **Calibrated partial observability:** each affective state is expressed weakly and differently in each modality group (stress: HRV-dominant; engagement/frustration: speech-dominant; MES weak for stress). Cultural display rules attenuate expressed signals only — never latent states or physiological HRV.
- **Labels** are binarized at reference-population quantiles (70th/30th percentile), computed after burn-in; positive-class prevalence is 25–33% in the reference population and 24–38% across held-out test sets.
- **Splits are by worker** (70/30); recognition experiments additionally report 5-fold × 5-repeat worker-grouped cross-validation.
- **E10** runs five arms with shared seed sets: business-as-usual; model-targeted (fused stress model, weekly closing-hour snapshot, ≥ 0.6 threshold — the E9 precision-oriented operating point, whose hourly alert rate is 23.2%); volume-matched random (the same number of workers per week, chosen uniformly); treat-everyone; and an oracle bound that replays the model arm's per-week flag volume while selecting the truly highest-stress workers (perfect knowledge at matched volume). All arms share 55% human acceptance, identical dynamics, and the activated disturbance-event machinery.
- **E10 economics:** replacement cost 26,000 USD per turnover; annual system cost 60,000 USD; intervention delivery cost 30 USD per executed career conversation. The within-noise defect difference is not monetized.
- **The E6 drift alarm** is a label-free population-stability-index (PSI) detector on input features (max per-feature PSI vs. a reference window, threshold 0.25), evaluated over 20 shifted and 20 unshifted validation pairs alongside the labelled accuracy-drop rule.
- **The Table 12 sensitivity grid** uses a simplified flagging rule (stress or disengagement probability ≥ 0.6, 5 replications per cell), so its levels are not directly comparable to Table 11 — as disclosed in the manuscript.

## Headline results (all reproducible from `results/`)

- **Recognition is state-dependent (E2):** best single-modality balanced accuracy on held-out workers — wearable HRV 0.794 for stress, speech 0.831 for engagement, speech 0.816 for frustration; early fusion reaches 0.792 / 0.799 / 0.725 and offers no reliable gain over the best single modality (cross-validated bAcc: 0.765 / 0.805 / 0.650).
- **Latency (E3):** per-sample inference 0.006–0.106 ms across model sizes (16 KB–22.8 MB serialized).
- **Resilience (E7):** trained fallback models recover up to 40 pp of the accuracy lost to sensor failure.
- **Drift (E6):** the label-free PSI detector fires in 20/20 shifted pairs with 0/20 false alarms; under gradual drift it raises its alarm on day 2, well ahead of the accuracy collapse in the 10-day profile.
- **Scalability (E8):** batch cycle inference stays within 101–149 ms from 30 to 500 workers; serialized model size grows 13.5 → 174.8 MB.
- **Operating point (E9):** at threshold 0.6 — precision 0.772 at a 23.2% hourly alert rate.
- **Layer evaluation (E11):** context-aware L3 rules add +5.1 pp precision (82.4% vs. 77.3%) at a lower alert rate (18.3% vs. 23.1%); attributions recover the causal HRV channel (65.8% importance share; ablation 0.833 → 0.665); the fairness audit shows suppressed-expression groups are flagged 29.3% less often, and per-group calibration restores parity (equalized flag rate 0.203).
- **Closed loop (E10):** relative turnover reduction at matched volume — random −0.7% < model-targeted 4.7% < oracle 11.8% (t(29) = 2.68, p = 0.012); treat-everyone reaches 40.0% at 23× the intervention volume; the model arm alone is not individually significant (p = 0.17). At the conservative baseline parameters the economics are negative (net −18,675 USD/yr; net ROI −0.29×) — an honest negative result reported as such.
